# Agent Skills standard

Nothing to submit. The Agent Skills project (agentskills.io, an Agentic AI Foundation project since 2026-10-22)
publishes the specification and a reference validator, not a registry. The `skills/palanor/dist/agentskills/palanor`
folder passes `agentskills validate` (skills-ref 0.1.1) in this repo's CI.

Directories that index standard skills (skills.sh, ClawHub, LobeHub) are covered in the other files here.
